## 🆘 Common Issues & Solutions

### Issue: npm install fails
```bash
# Clear cache and retry
npm cache clean --force
cd frontend
npm install
```

### Issue: Can't connect to backend
- Backend URL: https://pharmacare-api.onrender.com
- Check if it's running: https://pharmacare-api.onrender.com/api/health
- Backend may sleep on free tier (first request takes 30-60 sec)

### Issue: CORS error
- Backend CORS is already configured
- If issue persists, check browser console for details

### Issue: Login doesn't work
- Check browser console (F12) for errors
- Check Network tab to see API responses
- Verify user exists in database
- Try creating a new user
